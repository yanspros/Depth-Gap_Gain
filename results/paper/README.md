# Curated paper-result assets

These files are minimal, non-audio numerical exports from frozen source assets.
They are sufficient for the repository's no-GPU table and figure scripts but
are not raw experimental logs, target manifests, ASR outputs, checkpoints, or
an invitation to rerun selection on held-out data.

- `dgg/`: camera-ready Table 1/2 rows and development-only DGG summary.
- `diagnostics/`: retrospective gradient/displacement/representation comparator.
- `robustness/`: post-hoc retention-threshold sensitivity.
- `functional_depth/`: post-hoc development-only restoration landscape and
  Holm-adjusted adjacent-comparison sensitivity.
- `figures/`: values used by `scripts/reproduce_fig2.py`.

See `docs/PAPER_MAPPING.md` and `docs/SOURCE_PROVENANCE.md` for roles and
source identities.
