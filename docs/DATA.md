# Data and model boundary

The repository contains only compact, non-audio numerical paper summaries. FLEURS audio and metadata, DDD material, prompt/speaker data, model checkpoints, ASR models, audio tokenizers, cached tokens, generated audio, and private manifests are excluded. Users must retrieve any public data and upstream model under their own account and applicable license.

Development and held-out panels must be kept separate according to a frozen experiment contract. Public result CSV/JSON files cannot be used to recreate or select a new experiment; they are for transparent paper-table and figure reproduction only.
