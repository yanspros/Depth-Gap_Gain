# Toy examples

The three JSON files in `toy_dgg/` contain fabricated target-level edit counts
for exercising only the DGG/Q16 implementation:

- `full28_case.json` → `Full-28`
- `late16_case.json` → `Late-16`
- `no_prediction_case.json` → `No Prediction`

They are not derived from any paper language, model, audio, evaluator, or
checkpoint.  They must not be cited as experimental evidence.
